# Project X: raw clip log

X is the 20-minute film "You Have Never Seen the World" (`script.md`), built from the user's raw clips, with the caption style in `tools/caption-style/`, words behind the subject (`tools/matte.py`), and sound effects on caption landings.

**Do not start building until the clips cover 20 minutes.** **Never use a clip twice:** each new file is compared with every clip already in `raw/` (exact file match, then a picture match on the first frame), and repeats are skipped. Clips arrive in batches. After each batch, report how many minutes it covers.

How screen time is counted: unique footage, plus looping where a clip loops cleanly (short loops up to about 3–5 seconds on screen, longer clips once or with one repeat).

Clips that look like they come from films or TV series (08, 18, 19) stay in: the user asked to keep them.
